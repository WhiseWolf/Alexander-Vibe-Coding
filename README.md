# Einsatzleitung – Alexanders Rettungsspiel

Ein kostenloses Browser-Spielprojekt. Die erste spielbare Version ist ein 2D-Prototyp für Einsatzentscheidungen. 3D, selbst fahren und selbst retten sind als nächste Schritte geplant.

## Spielen
`index.html` herunterladen und im Browser öffnen (zusammen mit `game.js` im selben Ordner).

## Alexanders Idee
- Feuerwehr, Rettung, Polizei; ein Spieler
- mehrere Notrufe gleichzeitig, Vorhut und Funkmeldungen
- Ressourcen selbst verteilen, auch Fehlalarme und schwierige Entscheidungen
- erster Einsatz: Flughafenbrand
- später Höhenrettung, Waldbrände, Ölunfälle, Wasserrettung

Alle Einsätze sind fiktiv und spielerisch vereinfacht.
